# Walkable-Blender

First-person walkthroughs of Blender models, in the browser (Three.js). Live at
<https://gallowshumorgaming.com/Walkable-Blender/>.

## The level

The page loads one level, `Castle.glb`, generated by `blender/build_castle.py`.
More can be added by putting a GLB next to `index.html` and adding an entry to
`LEVELS` at the top of the script; with two or more, the page opens on a picker and
each level gets a `?level=<id>` link.

Extra URL options: `?fly=1` (free camera, no collision; E/Q = up/down) and
`?pos=x,y,z,yaw,pitch` (start position in glTF coordinates, angles in degrees).

### What the viewer looks for in a GLB

- **`COL_*` meshes** are invisible collision geometry. If a level has any, the player
  collides only with those; otherwise every visible mesh is used.
- **An empty named `Spawn`** sets where the player starts and which way they face.
- **Point lights** (`KHR_lights_punctual`) become flickering torches.
- **Materials named `Art_<name>`** take their picture from `art/<name>.png` (or
  `.jpg` / `.webp`) when that file exists. See [`art/README.md`](art/README.md).

## The castle

`blender/build_castle.py` builds the whole castle procedurally: gatehouse and
drawbridge, courtyard with a sunken fighting pit, great hall (feast tables, fresco
panels), throne room, kitchen, armory and forge, tavern cellar under four guest
rooms, battlement walkways, and a tall tower with a spiral stair and top windows.

- about 21k triangles; repeated pieces (towers, battlements, arches, windows,
  furniture) are linked instances of 35 shared meshes
- seven tileable 1024 px textures generated by `blender/castle_textures.py` (no
  downloads, no third-party licences)
- frescoes and banners are ordinary image files in [`art/`](art/README.md): replace
  a file there to change what hangs on the walls
- a separate 4.3k-triangle collision mesh; stairs collide as smooth ramps
- 1.4 MB as GLB

Rebuild it (needs Blender, or `pip install bpy`):

```bash
blender --background --python blender/build_castle.py -- --out Castle.glb
# or
npm run build:castle
```

`blender/Castle.blend` is the same scene saved from Blender 4.5 LTS, for
editing by hand. To put an edited version on the site, export it as
`Castle.glb` (glTF Binary, WebP images) over the existing file.

## Development

```bash
npm install
npm start        # serve on http://localhost:8080
npm test         # sanity checks
npm run optimize # shrink textures inside Castle.glb
```
